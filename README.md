# Трекер рейсов SU1032 и SU1009

Локальная версия тёмной страницы для ежедневного наблюдения за рейсами:

- SU1032: Шереметьево → Калининград;
- SU1009: Калининград → Шереметьево.

Основной источник данных — официальное табло Шереметьево. Сборщик находит рейс
в табло, получает его внутренний идентификатор и затем читает детальную карточку
рейса SVO. Пропуски в истории можно заполнить проверенными значениями
Flightradar24; при последующем появлении официальных данных SVO они имеют
приоритет.

## Локальный запуск

```powershell
python -m http.server 8000 -d site
```

После запуска доступны:

- `http://127.0.0.1:8000/` — парные карточки (основной вариант);
- `http://127.0.0.1:8000/board.html` — компактное табло;
- `http://127.0.0.1:8000/timeline.html` — маршрутная шкала.

## Обновление данных

```powershell
python scripts/update_flights.py --data site/data/flights.json
```

Скрипт запрашивает текущий и предыдущий московский календарный день, обновляет
только найденные рейсы и сохраняет прежние значения при временном отсутствии
полей. Проверенный FR24-бэкфилл сохраняется, но не может перезаписать SVO. Если
SVO полностью недоступен, файл не перезаписывается.

Для одноразового заполнения доступной истории SVO можно запросить до 30 дней:

```powershell
python scripts/update_flights.py --data site/data/flights.json --days 30
```

SVO фактически возвращает только доступные ему даты. Публичная страница FR24
защищена Cloudflare и не подходит для автоматического сбора из GitHub Actions,
поэтому исторический бэкфилл добавляется только после ручной проверки. Для
полностью автоматического резерва потребуется официальный FR24 API и токен.

## Тесты

```powershell
python -m unittest discover -s tests -v
```

## GitHub Pages

`.github/workflows/update-and-deploy.yml` обновляет данные каждые 15 минут,
запускает тесты и публикует содержимое `site/` через GitHub Pages.
